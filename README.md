# Crazyflie @ UIUC Center for Autonomy

Central index for all Crazyflie 2.1 work at the UIUC Coordinated Science Laboratory (CSL), Center for Autonomy (CfA).

This repo holds no code. It points you to the right repo and the right person. Setup, demo, and hardware docs live in each linked repo.

## Access

- **Staff only:** `crazyflie-demo`. Do not share it with current ECE484 students.
- **Students:** use the course org starter repo only.

## Safety

No live flight without props-off bench testing first. The full pre-flight runbook is in `crazyflie-demo`.

## Adding Your Repo

1. Transfer it into `UIUC-Robotics`, or keep it where it is and link it here.
2. Add the GitHub topic `crazyflie`.
3. Open a PR adding a row to the table above.
